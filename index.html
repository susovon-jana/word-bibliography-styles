Install in minutes

Use a style in Microsoft Word.

01

Download

Pick a style above, review its features, then download the .xsl file to your computer.

02

Copy

Quit Word completely, then copy the file into your personal bibliography styles folder below.

03

Select

Reopen Word and choose the new style from References → Style. Update citations to refresh formatting.

Windows

%APPDATA%\Microsoft\Bibliography\Style

macOS

~/Library/Containers/com.microsoft.Word/Data/Documents/Bibliography/Style

Built to grow

Add a new style with one commit.

This site scans the styles/ folder automatically — through the live GitHub API and a catalog that is rebuilt on every push. There is no HTML to edit and no list to update by hand.
