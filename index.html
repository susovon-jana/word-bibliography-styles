Install in minutes

Use a style in Microsoft Word.

01

Download

Pick a style above and press Download — the .xsl file saves straight to your device.

02

Copy

Quit Word completely, then copy the file into your personal bibliography styles folder below.

03

Select

Reopen Word and choose the new style from References → Style. Update citations to refresh formatting.

Windows

%APPDATA%\Microsoft\Bibliography\Style

macOS

~/Library/Containers/com.microsoft.Word/Data/Documents/Bibliography/Style

Curated for accuracy

Every style is verified before it lands here.

Citation accuracy is too important to trust to unverified uploads — so files are not accepted via drag-and-drop, and the maintainer publishes styles only from a proper git workflow (VS Code), which also keeps the repository free of merge conflicts.

Want to contribute a style? The community forum is open: propose your file there, and after verification it will be published to this library.

Propose a style in the forum ↗ Read the contribution guide

Maintained by Susovon Jana, Ph.D. — verified files are pushed via VS Code to keep history clean.

  1. 1
    Propose

    Open a thread in the forum with the style file (attach or link), its source, and why it should be included.

  2. 2
    Verify

    The maintainer tests the .xsl in Word, checks reference formatting and citation accuracy.

  3. 3
    Publish

    Approved files are committed via VS Code to main — the site picks them up automatically.
